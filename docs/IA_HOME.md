# Homepage information architecture

**Goal:** One job, three pillars, one primary CTA — match product-app cognitive simplicity.

**Positioning:** Nationwide AI print-to-mail + online Certified Mail. Lockup: **AI print to mail**. Slogan: **You upload. You approve. We produce.** Wichita only on About / footer / schema address.

## Home sections (exactly 6)

| # | Section | Content |
|---|---------|---------|
| 1 | Hero | H1 = slogan (`You upload. You approve. We produce.`). One factual lead. Get started / How it works. No boxed cite, no chips, no “Available now” eyebrow. |
| 2 | Pillars | Print and mail · Proof (Certified) · **AI setup, you approve** (MCP as body link only) |
| 3 | How it works | **3** steps + link to full `/how-it-works` |
| 4 | Trust | Nationwide + Postalocity stack + `/about` + `/address-verification` |
| 5 | FAQ | **6** questions max (what / available / upload / Certified / statements / billing); all closed |
| 6 | Get started | Form + one primary phone + email; 316 as secondary line |

## CTA hierarchy (site-wide)

1. **Primary:** Get started → `https://app.usmail.ai/`
2. **Secondary:** How it works / docs links (ghost)
3. **Human path:** One phone `888-667-5322` (Talk to mail ops); `316` only as microcopy

Nav: How it works · Print & mail · Certified Mail · Industries · Get started.

## Do not re-add

- Dual hero paragraphs / AEO dump beside lead
- Wichita or “mailing services Wichita” in titles or H1
- EDDM
- Hour counts or USPS transit promises
- “Learn more” 4-card hub under hero
- Formats grid on home
- 8 industry chips on home
- 11-item FAQ
- Equal dual-phone CTA clusters
