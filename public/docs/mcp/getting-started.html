Reference

Getting started

account → fund meter → portal and/or MCP. API keys later — not live.

Steps

  1. Get started

    Get started or call 888-667-5322.

  2. Register

    Create an account One account owns portal + MCP.

  3. Fund the meter

    Add prepaid balance. Production debits the meter — required for agent mail too.

  4. Portal first (optional)

    Optional: run one portal job first (upload → approve → produce → USPS).

  5. Connect MCP

    When enabled, connect with details we issue for your account (not published here).

  6. Call tools

    Call tools — see Tools reference.

Example intent

Upload notice.pdf + list.csv as First-Class.
Add Certified. Hold if cost > $50. Submit only if meter covers it.

Illustrative — not a live protocol.
