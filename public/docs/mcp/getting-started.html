Getting started

To use USMail.AI (portal or MCP when enabled): (1) get early access / open an account when available, (2) add funds to the prepaid meter, (3) submit jobs in the portal or via MCP tools under that account. A separate API product for pure agent billing is planned later — not required for the account + meter path, and not live yet.

Prerequisites

  • Organization or individual ready to send US physical mail
  • Ability for a human to register and fund a meter (card / payment when offered)
  • Documents in supported formats (PDF, Word, images, lists — see product pages)
  • Optional: MCP-capable client (Claude Desktop, Cursor, custom agent host, etc.) when server access is issued

Steps

  1. 1. Early access

    While coming soon, join the waitlist: Request MCP early access or call 888-667-5322.

  2. 2. Register

    Create a USMail.AI account when registration opens. One account owns portal access and (when enabled) MCP credentials tied to that org/user.

  3. 3. Fund the meter

    Add prepaid balance. Production mail draws down the meter. Agents cannot send paid mail without a funded meter on the account.

  4. 4. Portal first (optional)

    Confirm a job in the human portal: upload → AI setup → products → produce → USPS. Builds trust before automating via MCP.

  5. 5. Connect MCP

    When MCP is enabled for your account, install/configure the USMail.AI MCP server in your client using the connection details we provide at that time (host, auth). Exact config snippets ship with access — not invented here.

  6. 6. Call tools

    Use documented tools (upload, create job, status, etc.). See Tools reference.

Example agent intent (illustrative)

Natural language an agent might handle once tools are live:

Upload notice.pdf for recipient list list.csv as First-Class.
Add Certified Mail. Hold for my approval if cost exceeds $50.
Submit only if meter balance covers the quote.

Illustrative only — not a live command protocol. Tool names and approval UX may differ at launch.
