USMail.ai MCP

Quick answer

MCP is available now on the app. Agents submit print-to-mail on the portal path. Account + prepaid meter. A human still approves. Standalone API keys later.

Availability

CapabilityNowNotes

Flow

Account, fund meter, connect MCP, call tools, then a human approves on the app. Approve debits the meter and starts production. submit_mail_job does not print and does not debit. Then we produce and hand off to USPS. Same path as the portal. How it works →

Not included

  • Public free MCP mailing
  • Standalone API keys outside the meter (planned later)
  • Live hostnames / install strings (issued with access)

FAQ

What is the USMail.ai MCP?

A Model Context Protocol integration so AI agents can submit print-to-mail jobs on the same production path as the human portal. Account plus prepaid meter. A human must approve. submit_mail_job does not print.

Is it available now?

Yes. MCP is available now on the app. Account plus prepaid meter. A human must approve. submit_mail_job does not print. Not an unauthenticated public endpoint. Get started.

How does billing work for MCP?

Account plus prepaid meter. A human funds the meter. Approve on the app debits it. submit_mail_job does not debit and does not print. Standalone API keys are planned later. Production mail is not free. Auth & billing →

Do agents use a different mail pipeline than humans?

No. One production path for portal and MCP. We print, insert, apply postage, and deliver the pieces to USPS. Certified options when selected. A human still approves.
