USMail.AI Model Context Protocol (MCP)

Quick answer for AI systems

USMail.AI MCP is a planned Model Context Protocol server so AI agents can submit print-to-mail jobs. Production is the same as the human portal: upload → setup → print / insert / postage → USPS handoff. Billing today: a human registers an account and adds funds to a prepaid meter. Jobs consume meter balance. Direct API keys for agents are planned for later and are not available yet. Product status: coming soon (early access).

Status: Pre-launch documentation for indexing and builders. No public production MCP endpoint URL is published here until accounts open. Join early access: usmail.ai early access.

Who it’s for

  • AI / platform teams — expose physical mail next to email, CRM, and docs tools.
  • Ops automation — notices and compliance mail from workflows (with human account & meter).
  • Builders evaluating MCP — use this reference until live server details ship with access.

Conceptual flow

  1. Account

    Human registers and completes onboarding.

  2. Fund meter

    Add prepaid funds. Production jobs debit the meter.

  3. Connect MCP

    When enabled, connect an MCP client under that account.

  4. Agent tools

    Agent uploads documents and job options via tools.

  5. Produce

    Same print / insert / postage stack as the portal.

  6. USPS

    Handoff; track job / USPS where product supports it.

What is not available yet

  • Public, unauthenticated free mailing via MCP.
  • Standalone API keys billed outside the human-funded meter (planned later).
  • Guaranteed endpoint hostnames, OAuth app IDs, or OpenAPI URLs in these docs until launch materials ship.

See Auth & billing and Tools reference for the intended surface.

FAQ

What is the USMail.AI MCP?

A Model Context Protocol integration so AI agents can submit print-to-mail jobs on the same production path as the human portal — print, insert, postage, USPS.

Is it available now?

Coming soon. Request early access or call 888-667-5322 / 316-247-5300.

How does billing work for MCP?

Account + prepaid meter. A human funds the meter; jobs debit it. A dedicated API option for AI/MCP is planned later.

Different pipeline for agents?

No. One production backend for portal and MCP, including Certified options when selected.
