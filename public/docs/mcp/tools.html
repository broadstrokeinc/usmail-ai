MCP tools reference

The eight public MCP tools. Account + prepaid meter. A human must approve. submit_mail_job does not print by itself.

Billing: Approve on the app debits the meter. submit_mail_job does not print and does not debit. Auth & billing →

Tools

get_account_status

Account summary and meter balance for the authenticated session.

Returns account id · meter balance · MCP enabled

list_mail_products

Mail options available to the account (First-Class, Certified, Certificate of Mailing, …).

Returns option codes · names · short descriptions

upload_document

Upload a document or package (PDF, Word, images, lists as supported).

Inputs file · filename · content type · optional job id

Returns document id

create_mail_job

Create a job: documents, recipients/list, print options, mail options.

Inputs document ids · recipients/list · options · approval flags

Returns job id · draft status · estimate when available

get_mail_job

Job status, costs, production state, piece tracing; paid USPS tracking when selected.

Inputs job id

Returns status · timestamps · piece/IMB status · tracking id if any

submit_mail_job

Does not print

Submit a job for the human approval queue. Does not print. Does not debit the meter. A human on the app still approves. Approve debits the meter and starts production.

Inputs job id · optional confirmation

Fails validation · missing account

list_mail_jobs

List jobs for the authenticated account.

Returns job ids · statuses · timestamps

cancel_mail_job

Cancel if still cancelable (before irreversible production).

Inputs job id

Errors

CodeMeaning

not_cancelableAlready in production
not_availableMCP/platform not enabled
