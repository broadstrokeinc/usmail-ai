What you upload

The document you already produce. The list you already keep.

  • Statements

    Account and customer statements as PDF or Word, plus a recipient list.

  • Invoices

    Invoice packets and past-due notices. Same production path as statements.

  • Notices

    Compliance, formal, and regulatory documents. Optional Certified on the same job.

  • Recurring runs

    High-volume cycles use this path too. Same meter. Same mail date rules.

Formats are the ones you already export: PDF, Word, images, and CSV lists. You do not rebuild the cycle into a new system. You send the file the billing run already made.

How a cycle runs

Export. Upload. Setup. Approve this job. We produce.

  1. Export

    Pull the statement or invoice file from billing.

  2. Upload

    File plus list. PDF, Word, images, or CSV.

  3. AI setup

    Addresses and print options proposed for this run.

  4. You approve

    A human confirms the run in front of you.

  5. We produce

    Print, postage, deliver to USPS on your mail date.

Recurring volume uses the same five steps. A monthly statement run is still a job. A quarterly invoice packet is still a job. High-volume does not open a second path. The meter is the same meter.

The file and the list are two inputs. The file is the statement, invoice, or notice. The list is who receives a piece. Scan addresses from the file, import a CSV, or add them by hand. You choose how duplicate names and addresses are handled before you approve.

A multi-page export can be more than one mail piece. Split or cut the document by page, by text, or by logo in the app. The list still has to match the pieces you send. You review that on the job, not inside billing.

What this is not

  • Not a billing system

    We do not generate statements inside a core, ERP, or billing platform. You export or compose the document. We print and mail it.

  • Not a staffed mailroom

    We take production from upload to USPS. Incoming mail stays in your office. Mailroom →

  • Not document rewrite

    The statement copy stays yours. We do not edit balances, due dates, or notice language inside your system.

Volume, the meter, and the same path

High-volume statement cycles use the same production path as a one-off notice. There is no separate factory for a thick month. Account plus prepaid meter. Approve on the app debits it. Production mail is not free. We do not publish unit prices.

First-Class is the everyday path. If a cycle needs proof, add Certified on that job. If a cycle is ordinary delivery, leave it First-Class. You choose before you approve.

Statements and invoices FAQ

Can USMail.ai mail statements and invoices?

Yes. You upload the statement, invoice, or notice files and a recipient list. We print, insert, apply postage, and deliver the pieces to USPS.

Is this for recurring or high-volume mail?

Yes. Recurring and high-volume jobs use the same upload, approve, produce path. Account plus prepaid meter. No public unit prices. Production mail is not free.

Can statements go Certified Mail?

Yes, when the job needs formal proof. Add Certified Mail before you approve. Certified is never same-day. Certified is not for postcards. Certified Mail →

Do you replace our billing system?

No. We do not generate bills inside a core, ERP, or billing platform. You export or compose the document. We print and mail it.

Do you auto-send next month because last month ran?

No. You approve each job. Last month’s run does not mail this month. Recurring volume still waits on a human.
